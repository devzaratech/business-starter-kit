# Security Policy

This starter kit is designed for business SaaS applications and should be treated as security-sensitive from day one.

## Baseline Rules

- Never commit secrets.
- Use least-privilege credentials.
- Rotate credentials periodically.
- Keep tenant boundaries explicit.
- Log security-relevant events.
- Keep audit logs append-only where possible.
- Use TLS for public traffic.
- Use private networking for internal services.
- Prefer SSO/MFA for administration.

## Reporting Security Issues

Security issues must be reported privately to the repository owner.
