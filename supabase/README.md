# Supabase Profile

This directory contains optional Supabase/PostgREST assets.

Supabase is treated as an acceleration layer, not as the only possible backend model.

## Contents

- `migrations/`: SQL migrations
- `policies/`: Row-Level Security policies
- `functions/`: Edge Function placeholders
- `postgrest/`: PostgREST configuration notes

## Rule

PostgreSQL remains the canonical relational database. Supabase and PostgREST are optional provider profiles.
