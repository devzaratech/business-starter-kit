# Superpowers plans

The **single current implementation roadmap** is:

- [BSK Agent Master Plan v3 (2026-10-28)](2026-10-28-bsk-agent-master-plan-v3.md): multi-project/multi-domain/multi-VPS PaaS + IDP, dynamic environments, Tailscale, delivery pipelines per project, resource governance, dashboards, deployment engines, observability and optional privacy packs.

Start by implementing **PR0 only** from the roadmap. Older Foundation Guardrails plans in this folder are retained as historical implementation records and accepted ADRs remain authoritative for existing code. The v1/v2 conversational roadmaps are superseded and are not required for an agent to get started.

The roadmap is a **design**, not evidence that any planned functionality is already deployed or production-ready.
